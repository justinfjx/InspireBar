# InspireBar

InspireBar 是一个 macOS 菜单栏应用，用来看 Inspire 的点券余额、消耗和运行实例。开任务前扫一眼余额，跑任务时随时看看每小时的费用和 CPU／GPU 占用。

## 快速开始

运行需要 **macOS 14 或更新版本**。从源码构建需要 **Swift 6.2 或更新版本**的 Xcode 工具链。

1. 按 [Inspire CLI 的安装说明](https://github.com/realZillionX/InspireSkill)安装 CLI，在终端运行 `inspire login` 并完成网页授权。已有 CLI 会话时可直接构建。
2. 在仓库根目录运行：

   ```sh
   make start-release
   ```

   命令会在仓库根目录生成并启动 `InspireBar.app`。
3. 点击菜单栏的票券图标。应用默认每 **5 分钟**同步，点右上角的刷新按钮可以立即更新。

看不到图标时，先检查菜单栏溢出区或折叠工具。如果位置不够，在「设置 → 菜单栏」可切换到「仅票券」预设。

## 在菜单栏能看到什么

- **点券**：公共科研项目的个人余额、下次重置时间、当前费率，以及运行实例的项目、卡型、优先级和 CPU／GPU 占用率。
- **趋势**：本周余额实测曲线、预计耗尽时间、预计重置前剩余点券和历史扣费。
- **项目**：切换查看其他项目的余额、账单和实例。点券预测只用于公共科研项目。
- **用量与支出**：从面板底部打开，按项目查看最近 7、15 或 30 天的账单，或导出 CSV。

在「设置 → 菜单栏」选单行或双行，再拖动组件调整显示内容。在「设置 → 菜单」调整运行实例字段和项目名称颜色。

在「设置 → 通用」调整自动刷新频率、低功耗模式和开机启动。需要提醒时，在「设置 → 通知」选择提醒类型并允许 macOS 通知。

## 费率和预测怎么算

公共科研项目每周一 **10:00（UTC+8）** 重置为 **672 点券**。InspireBar 用本周的余额净消耗和已过去的时间估算日均用量，再从最新余额推算到下次重置。新周期刚开始或数据过期时，面板会等到有足够新的数据再显示预测。

实例费率表示此刻运行这些实例的成本：优先级 **1–3** 为 **0 点券／小时**，优先级 **4 起**按平台返回的费率计入。已扣点券以 Inspire 的历史账单为准。

## 登录与数据

采集在本机运行，直接访问 Inspire。应用启动 CLI 安装环境中的 Python，由 Inspire SDK 复用所选账号的会话。登录凭据仍由 CLI 管理；应用按账号将点券快照和历史保存在 `~/Library/Application Support/InspireBar`。

会话失效时，重新运行 `inspire login`，然后刷新菜单。要换账号，用 `inspire account use <账号别名>`，下一次同步会读取对应账号。

## 开发与许可

运行 `make test` 执行 Swift 和 Python 离线测试。构建、静态检查和旧档案迁移见[开发说明](docs/DEVELOPMENT.md)。
